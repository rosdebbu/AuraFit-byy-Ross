## About The Project
Most fitness apps focus only on the physical—calories burned, steps taken. AuraFit is built on the belief that your mental state is just as important. It's a simple tool I created to help you discover patterns between how you feel and what you do.

The goal isn't just to track data, but to provide actionable insights that lead to a healthier, more balanced life.

## Core Features
🧠 Daily Wellbeing Check-in: Log your mood, journal your thoughts, and practice gratitude to start your day with intention.

👟 Automatic Step Tracking: Seamlessly tracks your daily steps in the background using your phone's motion sensors.

🏋️‍♂️ Fitness & Nutrition Log: A comprehensive log for workouts and meals to keep you on track with your physical goals.

💡 Personalized Insights: The app analyzes your data to find connections, like how a morning walk might impact your mood.

🏆 Streaks & Motivation: Stay engaged by building streaks for daily check-ins and hitting your goals.

## Tech Stack
This project is built with a modern, full-stack approach:

Frontend: React, TypeScript, CSS

Backend: Java, Spring Boot (for the REST API)

Database: PostgreSQL

Mobile Integration: Utilizes Apple Health / Google Fit for seamless data syncing.

## Getting Started

Clone the repo

Bash

Install NPM packages for the frontend

Bash

npm install
Run the backend server (Instructions for your Java environment)

Start the frontend

Bash
